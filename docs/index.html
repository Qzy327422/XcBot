FAQ

常见问题

XcBot 主要能做什么？＋

它是一个有人格、会角色扮演的 QQ 聊天机器人：可以自定义性格与说话风格，用多种大模型自然对话，群聊私聊都能用。此外还支持插件扩展和可选的 Agent 工具调用。

怎么设定人格 / 角色扮演？＋

在 WebUI 的人格设定里写一段描述，定义它的性格、语气和边界即可。多轮对话中它会尽量保持这个角色，聊起来更有代入感。

支持哪些大模型？＋

兼容 OpenAI 格式接口的模型都可以接入，例如 DeepSeek 等，可以配置多个并设置轮换。

必须开启 Agent 吗？＋

不需要。Agent 是附加能力，关掉也能正常聊天和角色扮演。需要联网搜索、操作 QQ、执行多步任务时再开启即可。

需要付费吗？＋

XcBot 本身开源免费。你只需要准备一个大模型接口（部分模型有免费额度），以及运行环境。
