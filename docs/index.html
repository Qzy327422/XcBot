FAQ

常见问题

GitHub Pages 是免费的吗？＋

公开仓库可以直接使用 GitHub Pages。这个站点是纯静态文件，不需要购买服务器；如需自定义域名，只需另外购买域名。

必须配置付费搜索 API 吗？＋

不是。没有配置 Tavily 或博查 Key 时，联网搜索会回落到免费搜索源；付费 API 主要用于提升稳定性与结果质量。

Agent 能操作所有文件吗？＋

默认按会话使用独立工作区，管理员工具与普通工具分级授权。请只给可信管理员开放高权限操作。

Trace 会不会无限占用内存？＋

Trace 采用摘要索引与 SQLite 详情存储，内存和记录数量都有边界；WebUI 仍可读取历史详情。
