v3.0
Agent 工具调用 / 模型轮询重做 / 追踪页静默刷新：

- [Agent] 新增 Agent 能力，AI 可自主调用 28 个工具
  WebUI 左侧新增「Agent」板块，可开关工具和调权限。总开关关闭后
  完全不走 Agent 流程，与 v2.4 行为一致。

- [Agent] 工具分「所有人 / 仅管理员」两档，普通用户调管理员工具时
  AI 会如实说「这个操作需要管理员权限」，不假装成功。

- [Agent] AI 可调用插件，插件本身零改动。

- [Agent] AI 可设置定时提醒，到点用 AI 人格说出提醒语，支持重复。

- [Agent] 新增 /停止 与 /stop 命令，可中断正在执行的工具。

- [Agent] 工具集调整：去掉踢人和查任意 QQ 资料，拍一拍放开给所有人。
  主动发消息改为「汇报进度」用途，所有人可用，只能发当前对话。

- [Agent] 每个会话有独立工作区，AI 的文件读写默认落自己地盘。
  /reset 或「重置」会顺带清空当前会话的工作区。

- [Agent] 新增 send_file，AI 能把工作区里的文件发给用户下载。
  send_image 也支持本地图片（如 execute_python 画出的图表）。

- [Agent] 提示词精简，去掉重复的工具名单，减少幻觉。
  WebUI 的 Agent 页从 27 张卡片精简到 9 张，去掉群聊/私聊启用、
  群白名单、主动发消息白名单等多余设置项。

- [模型] 每次请求从第一个模型开始轮询，失败不冷却不禁用。

- [修复] 定时任务调度器从未真正运行过 —— 定时任务能创建但到点
  永远不会触发，现在修复。

- [修复] 同群两人同时说话时，后回复的会覆盖前一个人的聊天记录，
  现在串行处理。

- [修复] /停止 跨事件循环失效，工具执行后模型失败导致副作用重复
  执行（禁言被执行两次等情况），现在修复。

- [修复] 计算器安全防护可被绕过，改 AST 白名单。

- [修复] WebUI 鉴权可被完全绕过（设了 Token 也拦不住读配置），修复。

- [修复] 群聊并发时普通用户可能被当成管理员（管理员发言后普通
  用户拿到禁言、执行命令等权限），修复。

- [修复] 被关闭的工具仍能执行（关闭了执行命令工具，模型凭提示注入
  仍能调用），修复。

- [修复] 一批安全与一致性问题：配置备份可被 AI 读、符号链接可越出
  目录、图片链接缺内网校验、正则拒绝嵌套量词、读取配置密钥脱敏、
  Token 安全加固、插件恢复 TLS 校验等。

- [WebUI] 追踪页新增 Agent 工具调用链路，显示每次调用的工具名、
  参数、结果、耗时和副作用状态。静默刷新不再打断翻看。

- [WebUI] 修复配置值拼进 HTML 属性的 XSS。
