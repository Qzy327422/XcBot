v2.3
稳定性加固 / 日志 / WebUI 统计可视化优化：

- [稳定] 修复 bot/io_json.py 并发写入冲突
  原子写入新增跨平台文件锁：
  Windows 使用 msvcrt.locking，Linux/macOS 使用 fcntl.flock；
  防止 main.py 与 WebUI 同时写同一配置文件导致内容损坏。

- [稳定] Token 统计窗口裁剪移除 30 秒节流
  旧实现在高频场景下最多延迟 30 秒才裁剪窗口，导致短时统计偏高。
  现改为每次 add_usage 后立即裁剪，24h 窗口精度提升。

- [稳定] 新增全局未捕获异常日志
  main.py 注册 sys.excepthook，所有未捕获异常自动写入
  data/logs/error.log，不再只打印到控制台后丢失。

- [日志] stdout 输出新增时间戳前缀
  程序重定向到文件运行时（如 update-restart.log），
  每行 print 自动加 [HH:MM:SS] 前缀，方便日志追溯。
  交互终端下不加前缀，不影响正常使用体验。

- [日志] update-restart.log 新增重启分隔头
  每次自动更新重启前写入带时间戳的分隔行，
  方便区分多次重启之间的日志段落。

- [WebUI] 消息来源占比新增进度条
  图例区域每项新增带颜色的横向进度条，
  同时显示消息数与占比百分比（如 153 · 87%）。
  颜色跟随主题色变量，深色/浅色模式均可见；
  私聊用 --accent，群聊用 --accent3（紫色），色相区分明显。

- [优化] 新增 bot/constants.py
  集中管理 Token 窗口、节流时间、上下文长度等硬编码常量，
  便于后续统一调整，当前代码逻辑未变。

- [自检] 所有 Python 文件编译通过；app.js 语法检查通过。
