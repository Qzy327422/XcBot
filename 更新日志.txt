v3.5.0
- [知识库] 新增 WebUI 知识库页面，支持上传 TXT、Markdown、PDF 文档；默认使用所选提供商的 Embedding 模型向量检索，关闭向量开关后自动回退 SQLite FTS 全文检索。
- [知识库] 检索结果携带相关度随来源一并注入模型：向量模式为余弦相似度，FTS 模式按 BM25 排序并把命中分数归一化为 0～1；向量命中不足时用 FTS 补位，混合结果统一按相关度重排。
- [知识库] FTS 使用 trigram 三元组分词，中文查询可正常命中。
- [知识库] 向量索引绑定提供商 ID、模型名与向量维度，避免不同提供商同名模型或维度变更后混用旧向量；换模型后无命中会自动回退 FTS 覆盖全部文档。
- [知识库] Embedding 按顺序轮换提供商的全部 Key，大文档分批（每批 64 条）请求；全部失败才降级 FTS，过程与异常均输出日志。
- [知识库] 分块重叠在段落边界同样生效，且上限自动收紧为分块大小的一半，避免步长退化产生大量重复片段。
- [知识库] 注入上下文时按剩余字数截断当前片段并继续尝试更短片段，不再因首个片段超限而丢弃全部结果。
- [知识库] 索引失败的文档可直接重新上传触发重建，无需先手动删除；上传结果按实际状态提示（索引中 / 失败 / 已降级 FTS / 完成）。
- [知识库] 知识库内容改为注入用户消息而非额外 system 消息，避免破坏系统提示词的 KV 缓存命中。
- [提供商] 新增嵌入模型区域，与对话模型共用 Base URL 和 API Key；知识库以单一「提供商/模型名」选择器指定向量模型。
- [提供商] 手动添加模型改为 WebUI 内置输入弹窗，不再弹浏览器原生对话框；检测模型结果支持搜索筛选与多行选择。
- [图片] 收到图片时优先按模型轮换顺序选择可用多模态模型；没有可用多模态模型或图片读取失败时，明确告知模型无法读取图片，避免假装看图。
- [Agent] 工具调用完成后整理回复失败时不再直接输出降级提示：当前模型/Key 按「失败后额外重试次数」重试（默认 1，可在 WebUI 调整，设为 0 则直接轮换），仍失败则按轮换顺序切换下一个模型/Key，并携带已完成的只读工具链让新渠道直接总结。
- [Agent] 模型连续返回空响应耗尽重试后同样触发渠道轮换，不再当作成功向用户发送空回复。
- [Agent] 副作用安全策略：副作用工具（含全部 MCP 工具）执行后不切换渠道重跑整轮，避免禁言、发消息、写文件重复执行；仅调用过只读工具时关键词切换仍正常生效；重试期间收到 `/停止` 立即终止。
- [Agent] 新增「/reset 命令清空工作区」开关（默认开启）；清理前等待工具循环真正退出，避免「已清空」后文件又被写回。关闭后 /reset 仍清除聊天记忆但保留工作区文件。
- [功能] 入群欢迎语支持整句自定义，新增 {at} 占位符控制 @ 新成员的位置，不写 {at} 时 @ 自动置于最前；另加「欢迎时发送头像图片」开关（默认开启）。
- [WebUI 聊天室] 回复中的 <split> 分段标记按分段规则处理，不再原样透传给用户。
