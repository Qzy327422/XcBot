稳定性 / 安全 / 主流程修复：

- [严重] 修复 WebUI 切页动画连播 / 被掐断
  根因：切页后 refreshAll 在 page-anim 未结束时整页替换，CSS 动画重播或提前中断
  现仅真正切页播一次动画；动画进行中跳过同页整页刷新，时长与交错 delay 恢复正常手感
- [严重] 修复 app.js 语法错误导致 WebUI 卡在「加载中」
  render() 内容区分支多余 }，浏览器解析失败、脚本中断
- [严重] 修复聊天室默认无会话、点新建却出现两个
  根因：bootstrap 与 chatNew 互相 await 形成死锁；并发创建无服务端兜底
  现 /api/chat/sessions 空目录原子创建「默认会话」；前端拆出 chatCreateSession，进页只打开默认会话
- [严重] 修复 key_manager 轮换下标错位
  mark_success / mark_failure / disable_key / get_status_list / is_default_key
  原先把 rotation_index（原始 endpoints 下标，含空洞）当 model_slots 下标用
  现统一映射到真实槽位，失败后按列表顺序往后切
- [严重] 修复 OpenAI client 类级共享池被会话 clear/LRU 误关
  LimitedDeepSeekContext / ContextCompressor 实例关闭改为 no-op，避免并发会话互相踢连接
- [严重] 修复「引用聊天记录总结」temp_db 写死 key "0"
  handle_node_messages 现按真实 group_id 写入，与总结读取一致
- [严重] 修复 WebUI「拍一拍」功能开关无效
  处理链路补 is_feature_enabled("poke_reply")
- [严重] 修复私聊 Any 插件双执行
  handle_private_message 去掉重复 execute_plugins(True)
- [严重] 修复插件商店/上传路径穿越与 XSS 面
  zip 成员统一安全相对路径校验；上传 startswith 绕过修复；esc 转义单引号；
  商店按钮改 data-* + dataset；插件包约 12MB 上限；前端分块 base64

- [严重] 修复同 Key 多渠道故障转移失败
  同一 API Key 配给多个渠道/模型时，首渠道 403/余额不足后系统误认为
  Key 已试过，直接报"所有模型均失败"，不再尝试其他渠道。
  根因：tried_keys 用裸 Key 标识，无法区分同 Key 不同渠道。
  修复：改用 (base_url, model, key) 三元组；重试次数改为组合数；
        失败/冷却标记按三元组精确定位；主对话/转述/压缩摘要全路径一致。

- [严重] 修复切换日志显示纯数字（"自动 11 -> 1"）
  日志 from/to 改为"渠道ID/模型名"（如 1314mc/deepseek-v4-flash）；
  失败原因改为中文可读格式。

- [严重] 修复群总结历史数据分裂导致总结失效
  chat_db 加载时群号为字符串（JSON键），运行时用整数写入，
  形成两套键；落盘覆盖旧数据，/总结 读不到历史。
  修复：GroupKeyedChatDB 统一归一化为字符串，全链路透明。

- [严重] 修复 WebUI 聊天室并发乱序 + 断线残留消息
  同会话并发：History 可能 UserA/UserB/AssistantB/AssistantA。
  断线残留：用户消息已写盘但 LLM 未返回，留下孤立 user turn。
  修复：每个会话分配独立 RLock 保证事务串行；
        user 消息带 request_id，断线时精确回滚。

- [严重] 修复聊天室切换模型刷新失效
  前端只改内存对象，刷新页面恢复旧模型。
  修复：新增 POST /api/chat/model 接口落盘，前端 chatPickModel 改为
        async 异步调用；不可用模型拒绝并回滚下拉框。

- [中高] 修复 weather/quote/生图/查资料 开关永远无法关闭

  修复：补齐四个键到 FEATURE_META 和 DEFAULT_FEATURE_SWITCHES。
